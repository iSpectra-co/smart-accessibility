Accessibility Matters

Over 1 billion people worldwide live with some form of disability. Building accessible web experiences ensures your content reaches everyone, regardless of ability.

What this widget helps with

  • Visual impairments — high contrast, large fonts, screen reader
  • Motor difficulties — cursor guides, keyboard navigation
  • Cognitive disabilities — dyslexic font, focus mask, pause animations
  • Color blindness — saturation control, custom color palettes
"The power of the Web is in its universality. Access by everyone regardless of disability is an essential aspect." — Tim Berners-Lee

Feature Overview

🎨 Color Modes

High contrast, inverted, dark/light themes, and custom color swatches for text, links, and headings.

📝 Typography

Font size boost, OpenDyslexic font, letter spacing, and text alignment controls.

🔍 Focus Aids

Reading ruler, focus mask, cursor guide line, spotlight, and reading bar.

🔊 Tools

Read selection aloud, screen reader mode, and talk-to-write dictation.

🌍 Multi-language

Built-in EN, AR, FR, ES, DE support. Add more via extraLanguages config.

♿ Profiles

One-click presets: Blind, Color Blind, Dyslexia, Low Vision, ADHD, Seizure-safe.
