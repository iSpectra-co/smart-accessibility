One line to install

Drop a single <script> tag before your closing </body>. No npm, no bundler, no JavaScript configuration needed.

HTML 
<!-- before </body> -->
<script src="awidget.js"
  data-lang="auto"
  data-theme="auto"
  data-position="right"></script>

Accessibility Matters

Over 1.3 billion people worldwide live with some form of disability. Building accessible web experiences ensures your content reaches everyone — regardless of ability, device, or context.

What this widget helps with

  • Visual impairments — high contrast, large fonts, screen reader
  • Motor difficulties — keyboard navigation, large cursor, cursor guide
  • Cognitive disabilities — dyslexic font, focus mask, pause animations
  • Color blindness — saturation control, custom color palettes
